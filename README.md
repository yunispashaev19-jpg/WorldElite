# WorldElite

Global wealth intelligence platform.

## Features
- 3381+ billionaires with full profiles
- Companies with financials
- Search, Highest / Lowest, country filters
- Rankings (Wealth, Companies, Countries)
- World Bests
- Investments hub
- Login / Sign Up (local)
- Refresh Data

## Structure
- `index.html` — interface
- `style.css` — design
- `script.js` — logic
- `data.json` — all data (do not replace manually)
- `.github/workflows/update-data.yml` — auto update

## How to use
1. Open the site
2. Browse billionaires, companies, rankings
3. Use search and filters
4. Open any profile for biography, career, investments
5. Press Refresh Data to reload the latest data.json
