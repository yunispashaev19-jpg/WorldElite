# WorldElite

WorldElite is a global wealth and business intelligence interface.

## Features

- Billionaire rankings
- 3,000+ billionaire records
- Company directory
- Country filtering
- Search
- Highest / Lowest wealth sorting
- Refresh Data
- Billionaire profiles
- Company profiles
- Biographies
- Investments
- Stakes and ownership
- Annual salary
- Revenue
- Net profit
- Gross profit
- World Bests
- Login
- Sign Up
- Favorites
- Responsive luxury-style interface
- GitHub Pages deployment
